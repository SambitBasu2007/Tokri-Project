# Local product photos

Put your own photos here as `<productId>.jpg` (for example `4.jpg` for Shimla Apples).
`scripts/fetch-images.mjs` prefers these files over Open Food Facts so fresh produce and
missing barcodes still get a real image.

- 1:1 aspect ratio, object-fit contain, neutral background
- No third-party packaging shots unless you have the rights
- If a file is absent, the UI shows a flat grey placeholder with the product name
- Do not add copyrighted store imagery

Attribution for any Open Food Facts image remains: “Product images: Open Food Facts
contributors, CC BY-SA.”
