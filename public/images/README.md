# Local product packshots

The demo catalog ships with curated local photos named `<productId>.jpg` (for example `4.jpg` for
Shimla Apples). `scripts/build-catalog.mjs` normalizes each source to a 1000×1000 white canvas with
the product fitted inside an 820×820 area.

- 1:1 aspect ratio, white background, sRGB JPEG
- Retailer/brand packshots are used for product identification only in this demo
- Each product page links back to the listing the image came from
- Packaging and trademarks belong to their owners; this project claims no licence to them
- See `CREDITS.md` for the source of every image
- Do not reuse these files as if they were licensed stock photography
